# Retro Jam — privacy and support

Public support and privacy pages for Retro Jam by Semih Gülücü / Miniverse Games.

Live site: https://miniversegames1-hue.github.io/retro-jam/

Nine languages: English, Turkish, German, Spanish, French, Italian, Japanese, Korean, Brazilian Portuguese.

Only public policy/support content is included. No game code, credentials, gameplay artwork or personal player records belong in this repository.

Edit `content.json`, run `python3 generate.py`, then `python3 validate.py`. Serve locally with `python3 -m http.server 8000`. GitHub Pages serves the root of `main`. Open changes on a focused `codex/` branch and review a pull request before merging.
